## 🌟 Features

EmbyLens offers a variety of tools to make managing your media library efficient and straightforward.

### 📊 Dashboard

- **Overall Stats:** Easily view total media resources, number of libraries, and system status.
- **Audit Trail:** Keep track of maintenance operations to ensure system changes are logged and retrievable.

### 🐳 Docker Manager

- **Multi-Host Management:** Control your local Docker and manage multiple remote servers through SSH.
- **Container Lifecycle:** Start, stop, restart, or delete containers while viewing real-time logs—all presented in a user-friendly format.
- **Intelligent Updates:** Fetch the latest images and automatically rebuild containers with one click.
- **Compose Management:** Use the built-in manager to edit YAML files online and organize projects efficiently.
- **Batch Operations:** Perform bulk actions like "Start/Update" or "Stop" for all projects on the host.
- **Configuration Center:**
  - Visualize settings for image accelerators, proxies, and log rules.
  - Backup configuration changes automatically to ensure safety.
  - Cleanup unused images and build caches easily.
- **Quick Access:** Automatically resolve port mappings for seamless access.

### ♻️ Dedupe Ultimate

- **Multi-Dimensional Duplicate Find:** Identify duplicate movies and shows precisely.
- **Smart Selection:** Automatically assess versions based on resolution and encoding for optimal choices.
- **Safe Deletion:** Remove redundant files with one click to free up space.
